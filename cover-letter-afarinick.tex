I am applying for the Junior Software Engineer role at Afarinick. Afarinick's mix of cocoa rehabilitation, nurseries, and GIS/mapping is the kind of stack I have been training toward.

I have also worked with Ghana crop/soil data in a small machine-learning project, which is agriculture, not GIS, but it is the same domain.

I am currently a Software Engineer intern at AmaliTech (backend, Git, debugging, code review). I learn quickly, I document as I go, and I would rather fix an existing system with the IT Manager than only start greenfield toys. Meta's Django Web Framework certification is on my CV. I would welcome a conversation in Accra about how I can help maintain and extend Afarinick's backends and spatial data work.
